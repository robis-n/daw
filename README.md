# Nocturne Notes

A dark, minimalistic writing space for poems, lyrics, and reflections. Designed as a Windows-friendly Electron app with a calm, focused interface.

## Features

- Distraction-free editor with autosave
- Quick note list with search
- Favorite important drafts
- Offline-first local storage

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Launch the app:

```bash
npm start
```

## Future Enhancements

- Cloud sync with optional end-to-end encryption
- AI-assisted prompts and gentle editing suggestions
- Tagging, collections, and export formats
